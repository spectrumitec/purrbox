Docekr Registry

You may tag and upload the image to a docker registry. This is a simple example of pushing to a local registry if you have one configured. The images you create and push to the registry can be used in your Kubernetes infrastructure if you have one.


Local Registy

Assuming you have a local registry setup on your network, this is how to push your image to it. 

$ docker tag purrbox:latest registry.network.local/purrbox:latest

$ docker login --username=user registry.network.local
Password:

Login Succeeded

Docker Container

Docker containers can be one of the easier methods of setting up a Purrbox server where not needing to install node and having flexability of running more than one container on the same server, leverage automation, compose and build scripts, etc. In some cases, you may want to run an HAProxy or NGINX container in front of multiple Purrbox containers. Since Purrbox can run as CommonJS or ECMAScript mode, you can also run two containers in different run modes so that you can support either approach to Node.js native coding style. It may also allow to run other projects in parallel like React, Apache/PHP, etc.

Purrbox URL mapping functionality lends well to mapping websites to different sub paths under the same hostname or FQDN to simply running websites on multiple Purrbox containers.

This example will focus only on the Purrbox container creation on a Ubuntu Linux 24.04 LTS.
